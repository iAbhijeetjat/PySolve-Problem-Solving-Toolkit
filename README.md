# PySolve - Problem Solving Toolkit

## Overview
PySolve is an interactive, menu-driven Python application that implements core problem-solving algorithms and data structure techniques. It was built as a CSE academic project to demonstrate fundamental algorithms, number theory methods, and array/data structure operations through a clean, modular codebase.

## Features
- **Fundamental Algorithms:** Factorial, Fibonacci Sequence, Reverse a Number, Base Conversion (Binary/Octal/Hexadecimal)
- **Number Theory Tools:** GCD, Prime Number Checker, Square Root, Prime Factorization, Fast Power Computation
- **Array & Data Structure Lab:** Array Reversal, Find Maximum, Remove Duplicates, Kth Smallest Element, List/Tuple/Set/Dictionary demonstrations
- Simple, interactive menu-driven interface
- Input validation and error handling

## Technologies/Tools Used
- Python 3.14
- VS Code
- Git & GitHub for version control

## Steps to Install & Run
1. Make sure Python 3.x is installed on your system
2. Clone this repository:

git clone https://github.com/iAbhijeetjat/PySolve-Problem-Solving-Toolkit.git

3. Navigate to the project folder:

cd PySolve-Problem-Solving-Toolkit

4. Run the program:

python main.py


## Instructions for Testing
1. Run `python main.py`
2. Use the main menu to choose a module (1, 2, or 3)
3. Select any operation within that module and provide the required input when prompted
4. View the output printed in the terminal
5. Type `0` at any menu to go back, or exit from the main menu
