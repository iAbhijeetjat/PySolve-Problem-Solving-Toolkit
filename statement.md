# Problem Statement

## Problem Statement
Students learning problem-solving and Python programming often struggle to practice and visualize core algorithms (factorial, Fibonacci, GCD, prime numbers, array operations, etc.) in an organized, hands-on way. There is a need for a single, easy-to-use tool that consolidates these fundamental algorithms into one interactive application for learning and practice.

## Scope of the Project
This project implements a console-based, menu-driven Python application covering three major algorithmic areas: fundamental algorithms, number theory/factoring methods, and array/data structure techniques. It is intended as an academic demonstration of applying problem-solving concepts using Python, not a production-scale software system.

## Target Users
- CSE/Programming students learning algorithmic problem solving
- Anyone wanting a quick reference tool to test basic algorithms

## High-Level Features
- Compute factorial, Fibonacci sequence, reverse a number, and convert number bases
- Perform number theory operations: GCD, primality check, square root, prime factorization, fast exponentiation
- Perform array operations: reversal, finding maximum, removing duplicates, finding Kth smallest element
- Demonstrate Python data structures: Lists, Tuples, Sets, and Dictionaries
